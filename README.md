# 규칙이 없는 놀이 시간, 무엇이 문제일까? — 모둠 결과 정리 웹학습지

5학년 도덕 6단원 「공동체를 정의롭게!」 1차시(교과서 88~89쪽) A3 모둠 활동지(포스트잇용)의 **최종 결과 정리판**입니다.

- 모둠이 포스트잇으로 오프라인 토의를 한 뒤, 함께 고른 생각을 상황 1~4의 「문제」「규칙」 칸과 「규칙이 있으면 ( ) 수 있어요.」 문장에 옮겨 씁니다.
- 「이미지로 저장」을 누르면 1920px 너비 PNG 한 장이 만들어집니다. 이 이미지를 패들렛에 올립니다.
- 휴대폰·태블릿·PC 모두에서 쓸 수 있는 반응형 화면입니다.
- 쓴 내용은 그 기기의 브라우저에만 자동 저장되며 어디로도 전송되지 않습니다. 「새로 쓰기」로 지울 수 있습니다.
